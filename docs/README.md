# Switchly

## Project Overview

Switchly is a Spring Boot application developed as part of a learning project.

## Technologies Used

* Java
* Spring Boot
* Maven
* Docker

## Project Structure

* api: Contains the Spring Boot application.
* docs: Contains project documentation.

## How to Run

1. Open the project in IntelliJ IDEA.
2. Navigate to the api folder.
3. Run the Spring Boot application.
